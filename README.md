## The entry

> One star. He comes to my gate every day, waves paper I can't eat, and the one time I finally caught his shoe he called ME the bad dog.

## Description

A one-line review from a dog about the mailman: a daily gate invasion, inedible paper, and the great injustice of being called the bad dog for finally catching the shoe. Written for the [make.fun bounty "The Dog Reviews the Mailman"](https://make.fun/bounty/u-motasimfuad-the-dog-reviews-the-mailman-87608f85).

## How to run

```sh
node main.ts
```

It writes the review to `/output/entry.txt` — one line, under 200 characters, no trailing newline.
